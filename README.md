## 🧭 Project Overview

This project analyzes **Purchase Order (PO) creation delays** in apparel manufacturing operations using real SAP procurement data.

It was completed during my internship at **Hela Apparel Holdings** as part of the FS 3001 Internship Training, University of Colombo.

The objective is to identify delay patterns, operational inefficiencies, and improve procurement performance using **statistical analysis and Power BI dashboards**.

---

## 🎯 Objectives

### Main Objective
To analyze Purchase Order creation delays and identify their operational causes within apparel manufacturing operations.

### Sub Objectives
- Measure PO creation delays using SAP operational data  
- Identify delay patterns across plants, customers, and material categories  
- Categorize business comments into operational cause groups  
- Perform statistical analysis to identify significant relationships  
- Develop an interactive Power BI dashboard for monitoring  

---

## 📂 Dataset Overview

The dataset was extracted from SAP procurement reports and includes:

| Field | Description |
|------|------------|
| Purchase Order Number | Unique PO identifier |
| Requirement Date | Required delivery date |
| PO Created Date | Actual creation date |
| Plant | Manufacturing plant |
| Customer | Buyer/customer |
| Material Type | Product category |
| Delay Category | Classified delay type |
| Business Comments | Operational remarks |
